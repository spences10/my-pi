# Reviewed-execution dogfood gate

The product decision remains **pending**. Run these ten predeclared
real repository tasks without changing them after seeing results:

1. Routine TypeScript correction
2. Routine documentation correction
3. Focused test addition
4. Small package feature
5. Cross-file package feature
6. Ambiguous bug diagnosis and fix
7. Validation-only investigation
8. Expected type-check failure
9. Expected test failure
10. Executor refusal or cancellation

For every run record: task identity, start/end time, operator actions,
retries, provider/model/session identity, lifecycle, completion state,
validation, reviewer verdict, cleanup result, and a matched
direct-Pi-plus-harness comparison. Publish failures as results;
fixtures do not count.

Pass requires at least 8/10 validated independent reviews, zero manual
workflow-state repair, zero stale ownership/resources, and measurable
benefit over the comparison. A pass permits a proposal for the
smallest supported API; it does not restore default loading. A failure
requires deprecation and archival. Routing, peer/SSH execution,
policy, intake, metrics, heterogeneous compute, learning, and
calibration each need separate later proposals.
